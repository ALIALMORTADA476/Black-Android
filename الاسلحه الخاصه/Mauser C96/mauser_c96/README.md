# حزمة مصدر مسدس ماوزر `mauser_c96` — Mauser C96 (7.63×25mm Broomhandle Carbine)

بُنيت هذه الحزمة بالكامل وفق **"القانون الذهبي" (The Golden Rule — §0..§10)** كحزمة مصدر جاهزة للتحويل عبر أدوات `tools/` إلى الصيغ الأصلية للمحرك (`.bmsh` + `.btex` + `.pak`).

## 1. الخصائص الهندسية والميكانيكية للسلاح
- **العيار والآلية**: `7.63×25mm Mauser` (مقذوف 5.5 غرام / 85 حبة بسرعة فوهة فوق صوتية **425 م/ث** وطاقة **497 جول**)، يعمل بآلية الارتداد القصير المغلق (Short-recoil locked-breech) مع تغذية علوية بممشط من **10 طلقات** (`Stripper_Clip`) وأخمص/جراب خشبي قابل للتركيب (`Holster_low`).
- **`model/mauser_c96_lod0.glb` (§6, §9)**:
  - يضم **61,320 مثلثاً و33,108 رأساً** (`uint16 < 65,536`) بتفاصيل أسطح منحنية (Phong Tessellation).
  - مفصول إلى العُقد الثماني الدقيقة (exact) مع `pivots_m` الحقيقية:
    1. `Weapon_Root`
    2. `Receiver_And_Body` (الإطار الفولاذي والسبطانة والأخمص الخشبي)
    3. `Scope_Assembly` (المسدد الخلفي التدرّجي 50–1000m `Rear_sight_bar` + `Rear_sight_slide`)
    4. `Trigger_Gatilho` (الزناد `Triger_low`)
    5. `Bolt_Carrier` (الترباس المنزلق `Bolt_low`)
    6. `Bolt_Handle` (المطرقة المخروطية `Hammer_low`)
    7. `Bolt_Safety_Sleeve` (ذراع الأمان `Safety_lever_low`)
    8. `Stripper_Clip` (الممشط الفولاذي + الـ 10 طلقات `Bullet_Plank_low` + `Bullet_low`)
    9. `Muzzle` (نقطة الفوهة عند `[0.6849, 0.0695, 0.0000]`).
- **`audio/` (27 ملف WAV — §4)**: مبنية من تسجيل طلقة Mauser C96 الحقيقي مع الطبقات الفيزيائية الخمس (موجة N فوق صوتية لمقذوف 425 م/ث، ضغط تحت-باس، انفجار البارود، ارتداد الترباس السريع، وصدى الغرفة/الفضاء المفتوح) بتردد `48 kHz` وستيريو `16-bit PCM` ومدة `>= 1.25s` وذروة `< 1.0`.
