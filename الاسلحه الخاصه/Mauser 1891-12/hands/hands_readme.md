# Kar98k Articulated Tactical Hands & Forearms (`hands/hands_lod0.glb`)

## 1. المطابقة الهندسية مع سلاح `kar_98`
- **الشبكة والهيكل العظمي**: `22,238` رأساً و`40,811` مثلثاً (`uint16` تحت سقف `65,536`)، مع `40` مفصلاً عظمياً بالأسماء الإنجليزية المطابقة تماماً للمحرك (`Shoulder_lft/rt`, `Elbow_lft/rt`, `Wrist_lft/rt`, `Finger1..4_Top|Mid|Tip_lft/rt`, `Thumb_Top|Mid|Tip_lft/rt`).
- **تثبيت مسكة البندقية (`Baked Rest/Grip Pose + InverseBindMatrices`)**:
  - **اليد اليسرى (`_lft`)**: تحتضن حاضن السبطانة الخشبي عند `Socket_LeftHand_Foregrip` (`[0.555, 0.012, -0.006]`) مع التفاف الأصابع الأربعة حول الجدار الأيمن للخشب (`Z = +0.006..+0.015, Y <= 0.024`) والإبهام حول الجدار الأيسر (`Z = -0.008..-0.018`) دون حجب خط رؤية المنظار.
  - **اليد اليمنى (`_rt`)**: تمسك بقبضة الأخمص عند `Socket_RightHand_Grip` (`[0.245, -0.018, 0.008]`)، وتضع طرف السبابة (`Finger1_Tip_rt`) بدقة مليمترية على نصل الزناد `Socket_TriggerFinger_IK` (`[0.319, 0.000, 0.002]`)، وتلتف الأصابع الوسطى والبنصر والخنصر أسفل القبضة بينما يلتف الإبهام أعلى عنق الأخمص.
- **الحركات المدمجة (`Embedded Skeletal Animations`)**:
  1. `idle_walk_sprint_fire`: مسكة الإطلاق مع حركة ضغط السبابة على الزناد.
  2. `bolt_cycle`: انتقال اليد اليمنى لإمساك كرة الترباس (`Socket_BoltKnob_IK`)، رفعها بزاوية `68°` (`[0.295, 0.046, 0.038]`)، سحبها للخلف `-0.088m` (`[0.207, 0.046, 0.038]`)، ثم الإغلاق والعودة للقبضة.
  3. `reload_stripper_clip`: فتح الترباس، وضع المشط عند `Socket_ClipThumb_IK` (`[0.335, 0.068, 0.000]`) وضغط الإبهام للأسفل لدفع الـ 5 طلقات، ثم إغلاق الترباس.
